# NAGAR DESIGN AI STUDIO

واجهة ويب تجريبية لإنشاء وإدارة تصميمات الصور. تعتمد واجهة React وTypeScript على خادم Express؛ وتعمل وظائف Gemini فقط عندما يُضبط مفتاح الخادم وتكون النماذج متاحة لدى المزود.

> **حالة المشروع:** نسخة أولية قيد التطوير، وليست أداة prepress أو CAD معتمدة. اقرأ قسم [القيود المعروفة](#القيود-المعروفة) قبل استخدام الملفات في الطباعة أو القص.

## الميزات الحالية

- إدارة مشاريع وبرومبتات محليًا داخل المتصفح.
- تمرير طلبات التحليل والتوليد إلى Gemini عبر خادم Express عند توفر إعداد صحيح؛ الفشل يعاد كفشل صريح ولا يستبدل بنتيجة تجريبية.
- تحويل raster إلى PNG أو JPEG أو WebP، وتصدير حزم بيانات JSON للمشروع والبرومبت.
- معاينة عتبة ثنائية لصور الليزر، دون توليد مسارات vector.
- إنشاء PNG بأبعاد بكسل مستهدفة مع علامات قص مرئية، دون تحويل لوني طباعي.

## القيود المعروفة

- لا يتضمن التطبيق تسجيل دخول Google/OAuth، ولا يدير حصص API أو يضمن عددًا مجانيًا من الطلبات.
- إعداد الحسابات والحصص الوهمية أزيل. تخزن مفاتيح Gemini في بيئة الخادم فقط؛ وأثناء ترحيل الإعدادات القديمة تزال بيانات الحسابات ومفاتيح API المخزنة في `localStorage`.
- لا توجد حاليًا vectorization حقيقية أو DXF/SVG لليزر. شاشة الليزر معاينة فقط، وقد عُطّل تصدير المسارات عمدًا. لا ترسل المعاينة إلى ماكينة.
- شاشة الطباعة تنتج PNG نقطيًا فقط. لا تُضمّن بيانات DPI، ولا توجد معالجة CMYK أو ملفات ICC، ولا تصدير PDF أو فحص فعلي لجودة الصورة المصدر. تحقّق مع المطبعة من مواصفاتها.
- بعض أدوات AI تعتمد على نماذج/واجهات المزود، وقد تتوقف بتغير صلاحيات النموذج أو الخدمة. لم يُختبر الاتصال الحي لأن ذلك يتطلب مفتاحًا صالحًا.
- حد معدل الطلبات الحالي محلي الذاكرة ومناسب لعملية خادم واحدة فقط؛ لا يغني عن المصادقة، تخزين rate limit مشترك، أو حماية إنتاجية كاملة.

## المتطلبات

- Node.js `^20.19.0` أو `>=22.12.0`.
- npm.
- مفتاح Gemini إذا رغبت باختبار وظائف المزود.

## التشغيل

```bash
git clone https://github.com/<OWNER>/<REPOSITORY>.git
cd <REPOSITORY>
npm ci
cp .env.example .env
```

ضع `GEMINI_API_KEY` في `.env` المحلي غير المتعقب، أو في مدير أسرار بيئة النشر. لا تحفظ المفتاح في ملفات مصدر أو مستودع عام.

```bash
npm run dev
```

يفتح الخادم الواجهة وواجهات API على `http://localhost:3000`.

## التحقق والبناء

```bash
npm run lint
npm run build
npm start
```

يتوفر سجل التطوير والقرارات في `docs/`. راجع أيضًا `docs/AUDIT_REPORT_AR.md` و`docs/DEVELOPMENT_PLAN_AR.md`.

## شجرة مختصرة

```text
src/                 واجهة React وحالة التطبيق
server.ts            Express وواجهات Gemini
package.json         أوامر التشغيل والاعتماديات
package-lock.json    إصدارات الاعتماديات المقفلة
docs/                تقارير التدقيق والتطوير
```
